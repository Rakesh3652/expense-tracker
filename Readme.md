# Expense Tracker

A personal expense tracker built step by step, from a plain Java console app to a full-stack app deployed on AWS.

## Roadmap

- [ ] Phase 1: Project setup and Git
- [ ] Phase 2: Console app in core Java
- [ ] Phase 3: PostgreSQL database schema
- [ ] Phase 4: Spring Boot REST API with JWT auth
- [ ] Phase 5: React dashboard
- [ ] Phase 6: Docker and CI/CD with GitHub Actions
- [ ] Phase 7: Deployment on AWS

## Tech stack

Java, Spring Boot, PostgreSQL, React, Docker, GitHub Actions, AWS
